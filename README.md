# chon.dev

Personal portfolio for Jimson Ilog.

## Local development

```bash
npm install
npm run dev
```

## Netlify

Connect this folder to Netlify or push it to GitHub and let Netlify build it:

- Build command: `npm run build`
- Publish directory: `dist`

The contact form submits to the configured Formspree endpoint using an AJAX
POST. Configure the recipient and notification settings in Formspree.
